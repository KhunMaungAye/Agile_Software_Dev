# Campus Lost & Found Web App — Agile Software Development Lab

An AI-accelerated web platform designed for university students to report, track, search, and reclaim lost items on campus efficiently.

Developed with the acceleration of AI Coding CLI Agents (**Antigravity CLI** and **Gemini 3.7 Flash**).

## MVP Scope

- User Authentication & Student Verification
- Interactive Lost / Found Item Reporting with Photo Uploads
- Real-Time Notification & Claim Verification System
